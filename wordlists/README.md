# 词库格式说明

`wordlists/` 是所有词库的唯一源头。修改后运行 `python3 tools/build.py` 同步到 `skills/`。

## 文件头

```
# 以 # 开头（但不是 ##）的行是注释
@industry: beauty        # 行业代号，对应 --industry 参数，也是文件名
@title: 美妆个护          # 报告中显示的行业名
```

## 分类

```
## 分类名 [高危]
```

风险等级：`高危` / `中危` / `低危`，省略时默认 `中危`。

- **高危**：违反广告法或平台明令禁止，出现就大概率限流/下架（极限词、医疗功效、导流、承诺保证……）
- **中危**：需要资质或依据才能用，或特定语境下违规（需注册的功效词、站外平台提及、营销话术……）
- **低危**：容易被判定为标题党或影响推荐（震惊、必看、绝了……）

## 词条

```
词 | 替换建议1、替换建议2 | 例外1、例外2
```

- 列之间用 **空格 + `|` + 空格** 分隔；第 2、3 列可省略。
- 替换建议、例外都用 `、` 分隔。
- **例外**：如果命中位置完全落在某个例外词里就不报。例如 `第一 | 口碑很好 | 第一次、第一天` 不会把“第一次”报出来。
- 以 `re:` 开头表示 Python 正则（忽略大小写），例如：

  ```
  re:[0-9一二三两四五六七八九十几]+天(见效|美白) | 坚持使用有改善
  re:年化(收益)?\s*[0-9.]+\s*% | 历史数据仅供参考
  ```

  正则内部可以使用 `|`，只要两侧没有空格。

## 匹配规则

- 不区分大小写，检测前会把全角字符转半角（`ＶＸ` → `VX`，`１００％` → `100%`）。
- 会额外在“去掉空格、标点、常见表情符号”的文本上再匹配一次，用来抓“微 信”“v·x”“薇❤信”这类拆分写法。
- 同一位置被多个词命中时只保留最长的（“全网第一”优先于“第一”）；长度相同时行业词库优先于通用词库。
