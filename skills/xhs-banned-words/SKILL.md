# 小红书违禁词 · 总 skill（全行业）

本 skill 帮你在小红书创作中做两件事：

1. **检测**：找出文案里的违禁词、限制词，标出风险等级，给出合规替换。
2. **写作**：帮用户写小红书文案时，从一开始就避开这些词，写完再自检。

它合并了全平台通用词库和 9 个行业词库。如果用户只做某一个行业，也可以单独使用对应的行业 skill（`xhs-banned-words-<行业>`）。

## 文件说明（路径相对于本 skill 目录）

| 文件 | 内容 |
|---|---|
| `references/general.txt` | 全平台通用红线：极限词、承诺保证、虚假背书、站外导流（含谐音拆分）、营销诱导、封建迷信、医疗功效、情绪标题党 |
| `references/beauty.txt` | 美妆个护 |
| `references/medical.txt` | 医疗健康 / 医美 |
| `references/food.txt` | 食品 / 滋补 / 保健品 |
| `references/maternal.txt` | 母婴育儿 |
| `references/education.txt` | 教育培训 |
| `references/finance.txt` | 金融理财 |
| `references/home.txt` | 家居装修 / 清洁 |
| `references/fashion.txt` | 服饰珠宝 / 奢侈品 |
| `references/pet.txt` | 宠物经济 |
| `scripts/xhs_check.py` | 检测脚本（Python 3.8+，零依赖） |

词库格式：`## 分类 [高危/中危/低危]` 下每行一个 `词 | 替换建议 | 例外`，`re:` 开头的是正则。

## 第一步：判断行业

根据文案内容（或用户说明）选择 `--industry` 参数，**可以多选**，通用词库始终启用：

| 行业 | 参数 | 典型内容 |
|---|---|---|
| 美妆个护 | `beauty` | 护肤、彩妆、香水、洗护、美发 |
| 医疗健康/医美 | `medical` | 健康科普、疾病、医美、微整、口腔、中医理疗 |
| 食品/滋补/保健品 | `food` | 零食、饮品、养生、药食同源、代餐、保健品 |
| 母婴育儿 | `maternal` | 奶粉、辅食、婴童用品、宝宝洗护、孕产、早教 |
| 教育培训 | `education` | 课程、考研考公、考证、学历提升、K12、留学 |
| 金融理财 | `finance` | 理财、基金、股票、保险、贷款、信用卡、副业收入 |
| 家居装修/清洁 | `home` | 装修、建材、家具、清洁用品、智能家居 |
| 服饰珠宝/奢侈品 | `fashion` | 穿搭、鞋包、珠宝黄金、文玩、二奢 |
| 宠物经济 | `pet` | 猫狗粮、宠物用品、驱虫、训练、活体买卖 |

**跨行业很常见**：例如“黑芝麻丸生发”同时涉及 `food` + `beauty`；“孕妇护肤”涉及 `beauty` + `maternal`；“手串招财保值”涉及 `fashion`（迷信 + 投资）。拿不准时直接不加 `--industry`，全量检测。

## 工作流程

### A. 检测已有文案

1. 把文案写入临时文件（或直接用 `--text`）。
2. 运行（从其它目录运行时使用脚本完整路径，脚本会自动找到同 skill 下的 `references/`）：

   ```bash
   python3 scripts/xhs_check.py 文案.md --industry beauty,food --format markdown
   python3 scripts/xhs_check.py --text "要检测的文字"            # 全行业
   python3 scripts/xhs_check.py 文案.md --annotate                # 在原文中用【】标出
   python3 scripts/xhs_check.py 文案.md --min-risk 高危            # 只看高危
   python3 scripts/xhs_check.py 文案.md --format json             # 机器可读
   python3 scripts/xhs_check.py --list-industries                 # 查看词库
   ```

   发现高危词时脚本退出码为 1，可用于批量检查或 CI。
3. 脚本只做**字面匹配**（含全角转换与“微 信”“v·x”这类拆分写法）。拿到结果后，再按下方「各行业核心红线」做**语义复核**：没有违禁词但整体在暗示疗效、承诺结果、借用权威、引导站外交易的，同样要指出。也要排除误报（如“第一次”“最近”已内置例外，其它语境自行判断）。
4. 按这个结构回复用户：
   - **风险概览**：识别到的行业；高危 / 中危 / 低危各几处
   - **问题清单**：表格列出 原词 → 原因 → 建议替换
   - **改写后的完整文案**（保留原文语气、排版和 emoji）
   - **需要用户确认的事项**（备案、检测报告、品牌授权、账号资质等）

> 没有 Python 环境时：直接阅读 `references/general.txt` 和对应行业的 txt，逐条人工对照即可。

### B. 协助撰写文案

1. 先判断行业，读「各行业核心红线」中对应部分；需要更细的词时浏览对应行业 txt 的分类标题。
2. 按「通用写作守则」写作：用个人体验、使用场景、客观事实代替功效断言。
3. 写完后**必须**运行一次脚本自检，高危命中改到 0；中危/低危逐个判断是否修改。
4. 交付时附一句自检结论，例如：“已自检（beauty）：0 高危，1 处中危（‘必备’，口语用法，可按需替换）”。

## 各行业核心红线

**全平台通用**：极限词（最、第一、唯一、顶级、完美、100%、绝对、永久、万能、天花板、绝绝子、yyds）；承诺保证（无效退款、零风险、保证见效、彻底解决、X 天见效）；虚假背书（国家认证、专家推荐、驰名商标、特供专供）；站外导流（微信、vx、V心、绿泡泡、QQ、手机号、二维码、淘宝、加我、私我、主页找我，含谐音拆分）；营销诱导（万人疯抢、跳楼价、点击领奖、无真实活动的限时秒杀）；封建迷信（招财、转运、辟邪、开光、化解小人）；医疗功效（治疗、消炎、杀菌、降血糖等，任何普通商品禁用）。

- **美妆个护**：不涉及疾病治疗和医疗术语（消炎、抗菌、脱敏、药妆、医美级）；“修复”改“修护”；美白/祛斑/防脱需特殊化妆品注册证；“食品级”禁用；干细胞、胎盘素、激素等成分不写；“婴儿可用”需专项备案、“孕妇可用”需检测报告。
- **医疗健康/医美**：先看账号资质；达人禁推“三品一械”（药品、医疗器械、医美服务、保健食品）；普通商品不提具体疾病名和诊疗手段；不用患者形象和前后对比；不写老中医、祖传秘方、军医；不写 AI 看病/AI 诊断。
- **食品/滋补/保健品**：普通食品不宣称治疗预防和具体疾病；保健功能仅蓝帽子在获批范围可用且达人不得推广；补肾、养胃、祛湿等中医调理词禁用；药食同源只说属性不说功效；零添加/无糖/0卡需检测依据。
- **母婴育儿**：禁止任何替代母乳表述，0-12 月龄奶粉禁止种草；增强智力、补脑等一律违规；不做诊断医嘱；医用级、灭菌、防辐射禁用；不制造焦虑；保护儿童隐私；商业合作走蒲公英报备。
- **教育培训**：不承诺通过、拿证、就业、收入；不暗示命题人参与、内部押题；不编造通过率等数据；不贩卖焦虑和阶层叙事；学历考证不写免考、代考、包毕业；K12 不写小升初、提分 X 分、排名、奥数竞赛。
- **金融理财**：不承诺收益不暗示保本；无资质不荐股、不给点位、不晒实盘；贷款类秒批、包下款、征信修复出现即违规；不碰虚拟货币/NFT；不造暴富人设；不以送资料为名拉群导流；加风险提示。
- **家居装修/清洁**：零甲醛、100%环保需报告；“食品级”禁用；无认证不写杀菌抗菌；不写 100%除甲醛、永久防霉、永不变形；智能家居不写无法破解；零增项、全市最低价被重点拦截。
- **服饰珠宝/奢侈品**：材质宣称需报告（真皮要标皮革类型）；不写医疗功效；无授权不写正品承诺；原单尾单、1:1 复刻、正品平替、无授权明星同款直接删除；珠宝文玩不写保值升值和招财迷信；严禁线下看货、私下转账。
- **宠物经济**：普通宠物产品不宣称治病防病；不写医用级、兽医推荐（无资质）；原料安全需报告；不写爆腮、发腮神器；不写包教会、吃坏包赔；活体交易不写纯种保证、包活；不用侮辱性称呼。

每个行业更完整的词表和替换建议见对应 `references/<行业>.txt`。

## 常用合规替换速查

| 违规说法 | 合规替换 |
|---|---|
| 最好用、全网第一 | 我近期很常用、口碑很不错、人气之选 |
| 100%有效、保证见效 | 我用着效果明显、坚持使用有改善 |
| 美白、祛痘、消炎 | 提亮肤色、舒缓痘肌、舒缓泛红 |
| 修复 | 修护、肌肤维稳 |
| 增强免疫力 | 呵护自护力、日常滋养 |
| 减肥燃脂、溶脂 | 体重管理、体态管理 |
| 纯天然、零添加 | 天然原料、配料干净、配方精简 |
| 医生推荐、专家推荐 | 个人经验、营养师分享、宝妈实测 |
| 保过、包就业 | 阶段目标拆解、提供就业指导 |
| 稳赚不赔、保本 | 历史表现仅供参考，投资有风险 |
| 零甲醛、杀菌 | 环保达标符合国标、减少细菌滋生 |
| 原单、明星同款 | 工厂直出、同款风格 |
| 招财、旺运 | 寓意美好、自带好运感 |
| 加微信、私我 | 有问题评论区聊、站内商品卡下单 |

## 通用写作守则（所有行业都适用）

1. **主观感受代替客观断言**：多用“我觉得、个人感受、亲测、我用着、仅供参考”；少用“最、第一、100%、绝对、永久”。
2. **不做数字承诺**：不写“X 天见效、一周瘦 X 斤、提分 X 分、年化 X%”，除非有真实可查的依据。
3. **不导流**：不写微信/vx/V心/绿泡泡/QQ/手机号/二维码/淘宝/拼多多/主页找我/私我；平台能识别谐音、拼音、符号拆分。改为“评论区聊”或用站内商品卡。
4. **不借权威**：国家认证、专家推荐、医生推荐、驰名商标、特供专供，没有凭证一律不写。
5. **不搞迷信、不制造焦虑、不标题党**：招财转运、赢在起跑线、震惊、不看后悔。
6. **全环节检查**：标题、正文、首图文字、标签、评论区回复、主页简介、直播口播都要过一遍。
7. **资质备查**：涉及功效、安全、权威背书的内容，提前准备检测报告、授权文件、备案证明。
8. **AI 内容标注**：使用 AI 润色或作图时勾选“含 AI 合成内容”，不要声明原创。
