# 小红书违禁词 · 美妆个护

本 skill 帮你在 **美妆个护** 赛道做两件事：

1. **检测**：找出文案里的违禁词、限制词，给出风险等级和合规替换。
2. **写作**：在帮用户写小红书文案时，从一开始就避开这些词，写完再自检一次。

文件说明（路径相对于本 skill 目录）：

- `references/general.txt` —— 全平台通用红线词库
- `references/beauty.txt` —— 美妆个护行业专项词库
- `scripts/xhs_check.py` —— 检测脚本（Python 3.8+，零依赖）

词库格式：`## 分类 [高危/中危/低危]` 下每行一个 `词 | 替换建议 | 例外`，`re:` 开头的是正则。

## 工作流程

### A. 检测已有文案

1. 把用户的文案写入一个临时文件（或直接用 `--text`）。
2. 运行：

   ```bash
   python3 scripts/xhs_check.py 文案.md --industry beauty --format markdown
   # 或
   python3 scripts/xhs_check.py --text "要检测的文字" --industry beauty
   ```

   从其它目录运行时，用脚本的完整路径即可（脚本会自动读取同一 skill 下的 `references/`）。
   想在原文中标出问题位置加 `--annotate`；只看高危加 `--min-risk 高危`；要机器可读结果用 `--format json`。
3. 脚本只做**字面匹配**。拿到结果后，你还要按下面「本行业核心规则」做一遍**语义复核**，找出脚本漏掉的隐性违规（例如没有用违禁词但整体在暗示疗效、承诺结果、引导站外交易）。也要留意误报（比如“第一次”“最近”已在例外中排除，其它语境请自行判断）。
4. 按这个结构回复用户：
   - **风险概览**：高危 / 中危 / 低危各几处
   - **问题清单**：表格列出 原词 → 原因 → 建议替换
   - **改写后的完整文案**（保留原文语气和排版、emoji）
   - **还需用户确认的事项**（例如是否有备案、检测报告、授权）

> 没有 Python 环境时：直接阅读 `references/general.txt` 和 `references/beauty.txt`，逐条人工对照即可。

### B. 协助撰写文案

1. 动笔前先通读「本行业核心规则」和「常用合规替换」，必要时浏览 `references/beauty.txt` 的分类标题。
2. 按「通用写作守则」写作：用个人体验、使用场景、客观事实代替功效断言。
3. 写完后**必须**运行一次脚本自检，高危命中要改到 0；中危/低危逐个判断是否需要修改。
4. 交付时附一句自检结论，例如：“已自检：0 高危，1 处中危（‘必备’，已保留为口语用法，可按需替换）”。

## 本行业核心规则

依据：《化妆品监督管理条例》《化妆品标签管理办法》《化妆品功效宣称评价规范》《广告法》

- 化妆品**不能涉及任何疾病治疗**，也不能用医疗术语：治疗、消炎、抗炎、抗菌、杀菌、脱敏、药妆、医美级一律不写。
- “修复”是医疗用语，统一改成“修护”；“除皱”不行，“淡化纹路”可以（“抗皱”是法定功效，但需功效评价报告）。
- 美白、祛斑、防脱属于特殊化妆品功效，**产品没有注册证就不能写**，改用“提亮肤色、匀净肤色”。
- “食品级”在化妆品中全程禁用；“纯天然、零添加、无刺激、无毒无害”没有报告不能写。
- 干细胞、胎盘素、激素、抗生素、医美原液等违规成分不能出现在卖点里。
- “婴儿可用”需婴幼儿化妆品专项备案，“孕妇可用”需专项检测报告；小金盾只是分类标识，不能说“更安全”。
- 2026 年重点整治 AI 效果图、数字人、夸张对比 P 图：AI 内容必须标注“AI 生成内容”。

## 常用合规替换

| 违规说法 | 合规替换 |
|---|---|
| 美白 | 提亮肤色、匀净肤色 |
| 祛痘 | 舒缓痘肌、对痘痘友好 |
| 消炎/抗炎 | 舒缓泛红、改善肌肤不适 |
| 修复 | 修护、肌肤维稳 |
| 除皱/抗衰老 | 淡化纹路、弹润护理 |
| 100%纯天然 | 天然原料、成分温和 |
| 无刺激 | 温和亲肤 |
| 零添加 | 配方精简、不含XX成分（需有依据） |

## 改写示例

**改写前（多处违规）**

> 全网最好用的美白精华！7天美白，还能消炎祛痘，敏感肌、孕妇都能用，100%纯天然无刺激！

**改写后**

> 最近蛮常用的一瓶提亮精华，坚持用了一段时间，我觉得肤色看起来更匀净了，用着也挺温和的。（个人肤质感受，仅供参考）

## 通用写作守则（所有行业都适用）

1. **主观感受代替客观断言**：多用“我觉得、个人感受、亲测、我用着、仅供参考”；少用“最、第一、100%、绝对、永久”。
2. **不做数字承诺**：不写“X 天见效、一周瘦 X 斤、提分 X 分、年化 X%”，除非有真实可查的依据。
3. **不导流**：不写微信/vx/V心/绿泡泡/QQ/手机号/二维码/淘宝/拼多多/主页找我/私我；平台能识别谐音、拼音、符号拆分（如“薇❤”“v·x”）。改为“评论区聊”或用站内商品卡。
4. **不借权威**：国家认证、专家推荐、医生推荐、驰名商标、特供专供，没有凭证一律不写。
5. **不搞迷信、不制造焦虑、不标题党**：招财转运、赢在起跑线、震惊、不看后悔。
6. **全环节检查**：标题、正文、首图文字、标签、评论区回复、主页简介、直播口播都要过一遍。
7. **资质备查**：涉及功效、安全、权威背书的内容，提前准备检测报告、授权文件、备案证明。
8. **AI 内容标注**：使用 AI 润色或作图时勾选“含 AI 合成内容”，不要声明原创。
